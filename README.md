# NIMEX · ตรวจการวางบิล B-Quik

ระบบตรวจบิลซ่อมบำรุงจาก B-Quik เทียบกับใบเสนอราคาที่อนุมัติแล้ว

- `index.html` คือตัวระบบ ไม่มีข้อมูลอยู่ในไฟล์นี้
- `data.enc` คือข้อมูลบิลและสแกนที่เข้ารหัสด้วย AES-256-GCM (ใช้ PBKDF2 310,000 รอบ) ต้องใส่รหัสผ่านก่อนถึงจะเปิดดูได้

## อัปเดตข้อมูลทุกสัปดาห์
1. เปิดไฟล์ `NIMEX-BillCheck-….html` ตัวล่าสุดที่ได้รับ
2. ที่หน้าแรก กด "🔒 สร้างไฟล์ขึ้นเว็บ (data.enc)" แล้วตั้งรหัสผ่าน
3. ใน repo นี้ กด Add file → Upload files แล้วลากไฟล์ `data.enc` มาวางทับไฟล์เดิม จากนั้นกด Commit

ห้ามอัปโหลดไฟล์ `NIMEX-BillCheck-….html` ขึ้น repo เพราะไฟล์นั้นมีข้อมูลที่ยังไม่ได้เข้ารหัส
